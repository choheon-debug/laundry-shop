# 🧺 세탁소 장부

세탁소 접수·현황·손님·매출을 휴대폰으로 관리하는 웹앱. 로그인 없이 이 휴대폰에만 저장.

- ➕ 접수: 손님(이름·전화), 옷 종류(가격표 단추), 수량, 가격, 얼룩·흠 표시, 메모, 사진, 찾을 날, 선불/후불 → 접수번호(월일-순번)
- 📋 현황: 접수 → 세탁 중 → 완료 → 찾아감, 늦은 옷·안 받은 돈 모아 보기
- 🧾 한 건: 단계 바꾸기, 완료 문자(문자 앱), 접수증 보내기(카톡·문자·복사), 돈 받음 표시, 고치기·지우기
- 👤 손님: 이름·전화 뒤 4자리·접수번호로 찾기, 손님별 기록, 예전 손님 자동 추천
- 💰 매출: 오늘/이번 주/이번 달/지난 달, 날짜별, 많이 맡긴 옷, 안 받은 돈
- ⚙ 설정: 가게 이름·전화, 보관 알림 일수, 완료 문자 문구, 가격표, 백업(사진 포함)/불러오기

저장: 장부는 localStorage, 사진은 IndexedDB(긴 쪽 1200px JPEG). 손님 전화번호가 들어 있으니 백업 파일 취급 주의.
배포: GitHub Pages (Settings → Pages → main / root)
