# 🧺 세탁소 장부

세탁소 접수·현황·손님·매출을 휴대폰으로 관리하는 웹앱. 로그인 없이 이 휴대폰에만 저장.

- ➕ 접수(교재의 접수·검품·분류 반영): 손님, 옷 종류(가격표 단추·기본 세탁 방법), 수량, 가격, 세탁 방법(론드리/웨트/드라이/특수), 색 분류(흰색/연한 색/진한 색), 색상·상표, 조심할 점(물빠짐·장식·접착심지·코팅 등), 이미 있는 흠, 메모, 옷 사진·취급표시 사진, 주머니 확인, 흠 손님과 함께 확인, 손님 서명, 급함, 찾을 날, 선불/후불 → 접수번호(월일-순번)
- 📋 현황: 접수 → 세탁 중 → 완료 → 찾아감, 늦은 옷·안 받은 돈 모아 보기, 🧺 분류표(세탁 방법 → 색으로 묶기)
- 🧾 한 건: 단계 바꾸기, 완료 문자(문자 앱), 접수증 보내기(카톡·문자·복사), 돈 받음 표시, 고치기·지우기
- 🔍 찾기: 이름·전화·접수번호·옷·상표·흠·메모 등 과거 기록 전체 검색(기간 고르기), 손님별 기록, 예전 손님 자동 추천
- 💰 돈: 매출(오늘/이번 주/이번 달/지난 달, 날짜별, 많이 맡긴 옷, 안 받은 돈) + 지출(항목·금액·메모·영수증 사진, 매달 나가는 돈 다음 달에 한 번에 넣기), 남는 돈 = 받은 돈 − 지출
- ⚙ 설정: 가게 이름·전화, 보관 알림 일수, 완료 문자 문구, 가격표, 백업(사진 포함)/불러오기

저장: 장부는 localStorage, 사진은 IndexedDB(긴 쪽 1200px JPEG). 손님 전화번호가 들어 있으니 백업 파일 취급 주의.
배포: GitHub Pages (Settings → Pages → main / root)

## 세탁기능사 교재 반영
- 6절 접수·검품·분류: 품목·수량·색상·상표·취급표시, 기존 흠 손님과 확인(서명), 주머니 확인, 세탁 방법·색·섬유별 분류(분류표)
- 4·9절: 섬유 고르면 다림질 온도(혼방은 약한 쪽), 세탁 포인트, 추천 세탁 방법 / 특수품(가죽·모피·다운)
- 8절: 얼룩 성질(수용성·유용성·단백질·녹·먹·껌) → 처리법
- 10절: 취급표시와 세탁 방법이 안 맞으면 경고, 라벨 없으면 손님과 상의 / 세탁 사고 유형·원인·처리 기록(배상금 → 지출) / 5~6월 사고 주의 / 비대면 수거·배송: 수거 사진, 검품 사진 공유, 배송 사진
- 11절: 오늘의 점검(용제 누출, 잔류 세제·용제, 보관 세탁물 좀·곰팡이), 위생교육(매년 3시간) 알림

## 🏢 거래처 (기관 정기 세탁: 병원·소방서·요양원·호텔)
- 거래처: 종류별 기본 품목, 단위(장·벌·개·켤레·kg), 계약 단가, 정기 수거 요일, 납품까지 일수, 청구 기준(납품/수거 수량), 부가세 표시
- 회차: 품목별 수거 → 납품 수량, 재세탁·파손·분실, 수량 차이 자동 확인, 사진, 담당자 인수 서명, 수거·납품 확인서 공유
- 병원: 감염성 수량 따로, 소독 기록(감염성 분리, 세탁 전 소독, 운반용기·적재고 소독 일시·약품·사용량) — 의료기관세탁물 관리규칙 참고
- 소방서: 방화복 등 번호 관리 품목의 번호별 세탁 횟수·이력·상태 메모
- 월 정산서: 날짜×품목 표, 공급가액·부가세·합계, 청구함/입금 확인 표시, 💰 돈에 거래처 납품 금액 반영
